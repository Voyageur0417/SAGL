# Source publication and reuse licence

## Current decision

The repository maintainer explicitly authorised public publication of the SAGL research code and original trained model. This supersedes the earlier private-review publication decision. It is an instruction from the maintainer, not a fabricated institutional/data-provider clearance.

No MIT, Apache-2.0, GPL or other project-wide reuse licence has been selected for SAGL-owned material. The agent did not choose one automatically. The public repository is therefore described as a research source/model artifact, not as universally licensed open-source software. If the rights holders select a licence later, its scope and any model exceptions must be stated explicitly.
